- [x] Install the Android app on your phone
  Needed: the steezen-stt APK on the phone, plus three one-time permissions only you can grant.
  Why: Android only lets the owner of the phone enable accessibility services and pick the default assistant; the app cannot do it itself.
  Steps:
    1. Plug the phone in with USB debugging on and run `scripts/android.sh install` (or copy android/app/build/outputs/apk/release/app-release.apk to the phone and open it, allowing installs from that source).
    2. Open steezen-stt and press each button under Setup:
       - Microphone: Grant.
       - Accessibility service: if Android says "restricted setting", open App info, tap ⋮ → Allow restricted settings, then turn on "steezen-stt push-to-talk".
       - Default digital assistant: pick steezen-stt (and turn on "Hold power button for assistant" if your phone has that option).
    3. On the desktop: Settings → Export & import, tick API keys, set a passphrase, Export, and email the file to yourself. Open the attachment on the phone and enter the passphrase.
  Status: steps 1-2 done over USB on 2026-11-04 (installed, mic + notifications granted, accessibility on, steezen-stt is the default assistant). Moved step 3 and the power-button check to their own items below.

  Needed: Settings → System → Gestures → Press and hold power button → Digital assistant.
  Why: steezen-stt is now the default assistant, but Moto phones can map the power long-press to the power menu instead, and only the phone's own settings screen changes that.

  Needed: on the desktop, Settings → Export & import, tick the groups you want (API keys too), set a passphrase, Export, email the file to yourself; open the attachment on the phone and enter the passphrase.
  Why: the phone has no API key yet, so dictation can't transcribe until it does.
  Status: open

- [ ] Paste your Zen inbox token into the phone app
  Needed: Zen → Tools → inbox token (Generate one if it is empty), pasted into steezen-stt → Zen → Zen inbox token.
  Why: the long-press-power gesture uploads recordings to zen.steezen.com/api/capture, which rejects requests without the token once one is set. The desktop app has no field for it, so it was not in the export.
  Status: open
