- [x] Install the Android app on your phone
  Needed: the steezen-stt APK on the phone, plus three one-time permissions only you can grant.
  Why: Android only lets the owner of the phone enable accessibility services and pick the default assistant; the app cannot do it itself.
  Steps:
    1. Plug the phone in with USB debugging on and run `scripts/android.sh install` (or copy android/app/build/outputs/apk/release/app-release.apk to the phone and open it, allowing installs from that source).
    2. Open steezen-stt and press each button under Setup:
       - Microphone: Grant.
       - Accessibility service: if Android says "restricted setting", open App info, tap ⋮ → Allow restricted settings, then turn on "steezen-stt push-to-talk".
       - Default digital assistant: pick steezen-stt (and turn on "Hold power button for assistant" if your phone has that option).
    3. On the desktop: Settings → Export & import, tick API keys, set a passphrase, Export, and email the file to yourself. Open the attachment on the phone and enter the passphrase.
  Status: steps 1-2 done over USB on 2026-11-04 (installed, mic + notifications granted, accessibility on, steezen-stt is the default assistant). Moved step 3 and the power-button check to their own items below.

- [ ] Install steezen-stt 0.7.0 and the new Zen Assistant app, then switch the assistant on
  Needed: both APKs on the phone, then switches only the phone's owner can flip.
  Why: Zen Assistant is built (android/assistant) but no phone was connected over adb and the build machine can't run an emulator (no /dev/kvm), so neither app has been installed or tried on a device. steezen-stt 0.7.0 also moved its notification listener to a new class, so Android forgets that grant once and needs it again.
  Steps:
    1. Plug the phone in with USB debugging on and run `scripts/android.sh install` (installs both).
    2. Open Zen Assistant and follow Setup:
       - Zen phone control: Accessibility → Zen phone control → on. If Android says "restricted setting": App info → ⋮ → Allow restricted settings, then try again.
       - Keys: in steezen-stt, Export & import → Export with the "API keys" group and a passphrase → Share to yourself, then open the file with Zen Assistant (or paste the Anthropic and OpenAI/Groq keys by hand).
       - Default digital assistant: pick Zen Assistant if the power button should run the assistant (steezen-stt if it should dictate), then Settings → System → Gestures → Press and hold power button → Digital assistant.
       - Keep running in the background: Allow. Optional: the Assistant permissions you want (contacts, calls, SMS, calendar, notifications); each asks Android when switched on.
    3. Add the "Ask Zen" tile: pull down Quick Settings → edit (pencil) → drag Ask Zen in.
    4. Try: "set a timer for one minute", "turn on the flashlight", "skip this song", "open YouTube and search for lo-fi", then "text <someone> test" (it must show a confirmation sheet before sending).
    5. In steezen-stt, re-grant notification access if you use the earbud play/pause fallback (Setup shows it).
  Status: open
